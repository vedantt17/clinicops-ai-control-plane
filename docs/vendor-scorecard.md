# Vendor and Tooling Scorecard

The scorecard compares three integration approaches using synthetic planning inputs.

| Dimension | Weight | Meaning |
| --- | ---: | --- |
| Reliability | 35% | Expected workflow continuity and recoverability |
| Security | 30% | Authentication, data handling, auditability, and control surface |
| Implementation | 20% | Speed and complexity of integration and change |
| Cost | 15% | Relative operating and vendor cost |

Direct FHIR integration ranks first because it provides the strongest reliability and security profile when an EHR supports the needed resources. Portal automation is treated as a constrained fallback, not the default architecture. Scores are transparent scenarios, not vendor claims or completed procurement analysis.
